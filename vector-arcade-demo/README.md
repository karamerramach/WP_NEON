# Vector Arcade — bilingual WordPress theme demo

Open `index.html` in a browser. The preview uses local CSS and SVG files in this folder. The EN / FR selector works locally and remembers the selected language in browser storage.

`vector-arcade.zip` is the installable WordPress theme package.

## Publish the preview with GitHub Pages

Copy the contents of this folder (`index.html`, `style.css`, `assets/` and `vector-arcade.zip`) to the repository root or its `docs/` directory. Then enable GitHub Pages for that branch and publishing directory. No build step or external service is required.
